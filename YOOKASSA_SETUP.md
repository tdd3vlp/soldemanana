# Настройка платежей через YooKassa

## 1. Регистрация в YooKassa

1. Перейди на [yookassa.ru](https://yookassa.ru)
2. Зарегистрируйся или войди в личный кабинет
3. Создай магазин (Shop)

## 2. Получение API ключей

1. В личном кабинете YooKassa перейди в **Настройки** → **Ключи для API**
2. Скопируй:
   - **shopId** (идентификатор магазина)
   - **Секретный ключ** (secret key)

## 3. Настройка .env файла

Добавь в `.env` файл:

```bash
YOOKASSA_SHOP_ID=твой_shop_id
YOOKASSA_SECRET_KEY=твой_секретный_ключ
```

## 4. Настройка Webhook

Webhook нужен для автоматической активации подписки после оплаты.

1. В личном кабинете YooKassa перейди в **Настройки** → **Уведомления**
2. Добавь HTTP-уведомление:
   - **URL**: `https://your-domain.com/payment/yookassa/webhook`
   - **События**: 
     - ✅ `payment.succeeded` (платеж успешно завершен)
     - ✅ `payment.canceled` (платеж отменен)

## 5. Тестирование

### Локально (без webhook):
```bash
docker compose up -d bot
# В Telegram: /subscribe → Оформить PREMIUM
```

### На продакшене:
1. Задеплой бота на сервер с доменом
2. Настрой HTTPS (обязательно для YooKassa)
3. Укажи правильный webhook URL
4. Протестируй оплату тестовой картой

## Тестовые карты YooKassa

| Карта | Номер | CVC | Срок | Результат |
|-------|-------|-----|------|-----------|
| Успешная оплата | 5555 5555 5555 4477 | Любой | Любой | Оплата пройдет |
| Отказ | 5555 5555 5555 5599 | Любой | Любой | Оплата будет отклонена |

## 6. Переключение на боевой режим

1. В личном кабинете YooKassa переключись с **Test** на **Production**
2. Обнови `.env`:
   ```bash
   ENVIRONMENT=production
   YOOKASSA_SHOP_ID=production_shop_id
   YOOKASSA_SECRET_KEY=production_secret_key
   ```
3. Перезапусти бота:
   ```bash
   docker compose restart bot
   ```

## Проверка работы

```bash
# Логи бота
docker compose logs bot -f

# Проверка webhook (после оплаты должно появиться):
# "Subscription activated via YooKassa"
```

## Возможные проблемы

### ❌ Ошибка создания платежа
- Проверь правильность YOOKASSA_SHOP_ID и YOOKASSA_SECRET_KEY
- Убедись, что аккаунт активирован

### ❌ Подписка не активируется после оплаты
- Проверь, что webhook настроен правильно
- Проверь логи: `docker compose logs bot -f`
- Убедись, что домен доступен по HTTPS

### ❌ Платеж отклонен
- Используй тестовую карту 5555 5555 5555 4477
- Проверь, что в настройках YooKassa включен тестовый режим
